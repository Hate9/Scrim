## Q-024: Which CJK font, if any, to bundle for PDF headers and footers
**Asked by:** implementation, 2026-11-22
**Question:** 9.3 says header and footer text "uses a subset of a bundled Unicode font
(Noto Sans, plus Noto Sans CJK subset on demand), embedded into the PDF". Noto Sans
(Latin, Greek, Cyrillic, 0.6 MB) is bundled now. Noto Sans CJK is large: one weight of
the pan-CJK font is about 16 MB as OTF (about 20 MB as a collection); the
single-region subsets (for example Noto Sans JP, about 4.5 MB) each cover one region's
characters well and the others only partly. Symbols such as ✓ (U+2713, used in X-5) are
in neither font; they are in Noto Sans Symbols 2 or in common system fonts.

Scrim lays the header and footer out in its webview and stamps the result onto the
PDF, so the PDF writer subsets and embeds whatever fonts are used. The font choice is
therefore only about where the glyphs come from. Options:

1. Bundle Noto Sans CJK (all regions, one weight, about 16 MB more in the package).
2. Bundle one region's subset (about 4.5 MB); other scripts fall back to system fonts.
3. Bundle Noto Sans only; anything it lacks (CJK, symbols) falls back to the system's
   fonts, as the document body itself does. On a system without CJK fonts the body
   text of a CJK document would not render either.

**Interim behavior:** option 3. Header and footer text is set in the bundled Noto Sans
with the system's sans-serif fonts as fallback; X-5 runs with the system's CJK and
symbol fonts installed (CI installs `fonts-noto-cjk`). Marked `SPEC-QUESTION Q-024` in
`src-tauri/src/pdf.rs`.
