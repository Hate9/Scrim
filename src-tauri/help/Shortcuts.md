# Shortcuts

Ctrl is the modifier on Linux and Windows. Change any menu shortcut in `config.jsonc`
(`"shortcuts": { "Strong": "Ctrl+Shift+B" }`, by the menu item's English name).

## File

| Action | Keys |
|---|---|
| New / New Window | Ctrl+N / Ctrl+Shift+N |
| Open / Quick Open | Ctrl+O / Ctrl+P |
| Save / Save As | Ctrl+S / Ctrl+Shift+S |
| Preferences | Ctrl+, |
| Close / Quit | Ctrl+W / Ctrl+Q |

## Edit

| Action | Keys |
|---|---|
| Undo / Redo | Ctrl+Z / Ctrl+Y or Ctrl+Shift+Z |
| Copy as Markdown | Ctrl+Shift+C |
| Paste as Plain Text | Ctrl+Shift+V |
| Select Line / Styled Scope / Word | Ctrl+L / Ctrl+E / Ctrl+D |
| Delete Word | Ctrl+Shift+D |
| Jump to Top / Selection / Bottom | Ctrl+Home / Ctrl+J / Ctrl+End |
| Find / Replace | Ctrl+F / Ctrl+H |
| Find Next / Previous | F3 / Shift+F3 |
| Search in Folder | Ctrl+Shift+F |

## Paragraph

| Action | Keys |
|---|---|
| Heading 1–6 / Paragraph | Ctrl+1 … Ctrl+6 / Ctrl+0 |
| Heading level up / down | Ctrl+= / Ctrl+- |
| Table | Ctrl+T |
| Code Fences / Math Block | Ctrl+Shift+K / Ctrl+Shift+M |
| Quote | Ctrl+Shift+Q |
| Ordered / Unordered / Task List | Ctrl+Shift+[ / Ctrl+Shift+] / Ctrl+Shift+X |
| Indent / Outdent | Ctrl+] / Ctrl+[ |
| Move up / down | Alt+Up / Alt+Down |

## Format

| Action | Keys |
|---|---|
| Strong / Emphasis / Underline | Ctrl+B / Ctrl+I / Ctrl+U |
| Code | Ctrl+Shift+` |
| Strike | Alt+Shift+5 |
| Hyperlink | Ctrl+K |
| Insert Image | Ctrl+Shift+I |
| Clear Format | Ctrl+\ |

## View

| Action | Keys |
|---|---|
| Source Code Mode | Ctrl+/ |
| Focus / Typewriter Mode | F8 / F9 |
| Sidebar | Ctrl+Shift+L |
| Outline / File List / File Tree | Ctrl+Shift+1 / 2 / 3 |
| Zoom in / out / actual size | Ctrl+Shift+= / Ctrl+Shift+- / Ctrl+Shift+0 |
| Full Screen | F11 |
